# סבוני גוף טבעיים

אתר סטטי בעברית להצגת סבונים בעבודת יד ולהזמנה ב־WhatsApp.

## קבצים

- `index.html` — דף הבית, העיצוב וסינון המוצרים.
- `לבנדר מלטף.jpeg` — תמונת סבון לבנדר מלטף.
- `חמים ומעורר.jpeg` — תמונת סבון חמים ומעורר.
- `פרחוני.jpeg` — תמונת סבון פרחוני.

שמות התמונות בקוד חייבים להתאים בדיוק לשמות הקבצים, כולל הסיומת `.jpeg`.
התמונות נטענות בנתיבים יחסיים, כך שהאתר מתאים גם לכתובת של פרויקט ב־GitHub Pages.

## תצוגה מקומית

פתחו את `index.html` בדפדפן, או הריצו בתיקיית הפרויקט:

```sh
python -m http.server 8000
```

לאחר מכן פתחו את <http://localhost:8000>.

## פרסום ב־GitHub Pages

1. פתחו את המאגר ב־GitHub ובחרו **Settings → Pages**.
2. תחת **Build and deployment**, בחרו **Deploy from a branch**.
3. בחרו בענף **main** ובתיקייה **/ (root)** ולחצו **Save**.
4. לאחר סיום הפרסום, כתובת האתר תופיע בראש עמוד ההגדרות.

אין צורך בהתקנת חבילות או בתהליך build. קובץ `.nojekyll` מאפשר הגשה של האתר הסטטי כפי שהוא.
